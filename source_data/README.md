# Aggregate source data

These CSV files contain aggregate outputs only; no respondent-level records are included.

- `wave_sample_reproduction.csv`: wave-specific disease and eligible-profile counts.
- `transition_matrix_*.csv`: survey-weighted row percentages for the five-state transition matrices.
- `transition_four_type.csv`: four-category transition summaries by interval.
- `followup_disposition_by_baseline_state.csv`: follow-up status by interval and baseline questionnaire state.
- `diagnosis_consistency.csv`: adjacent-wave diagnosis consistency summaries.
- `newly_reported_diagnosis_profiles.csv`: profiles at the first positive diagnosis report.
- `final_primary_standardized.csv`: standardized primary-model probabilities, risk differences, and risk ratios.
- `final_interval_standardized.csv`: interval-specific standardized estimates.
- `model_coefficients_and_sensitivity.csv`: primary and sensitivity-model coefficients and confidence intervals.
- `unadjusted_transitions_by_hukou_residence.csv`: unadjusted group-specific weighted transition estimates.
- `transition_sensitivity_summary.csv`: descriptive sensitivity summaries.
- `baseline_by_hukou_residence.csv`, `baseline_covariate_missingness.csv`, and `baseline_standardized_differences.csv`: baseline descriptive and balance diagnostics.
- `respondent_interval_contributions.csv`: numbers of intervals contributed per respondent.
- `normalized_weight_distribution.csv`: analysis-weight diagnostics.
